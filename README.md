# 🤖 ReferralEarnBot

A powerful Telegram referral and rewards bot built with Python and MongoDB.

## ✨ Features

- 👥 Referral system
- 💰 Referral rewards
- 💵 Balance management
- 💸 Withdrawal system
- 📜 Withdrawal history
- 🔎 Advanced Find User
- 👤 Detailed user profiles
- 👥 Referral details
- 📊 Admin analytics
- 🚫 Block / Unblock users
- ➕ Add Balance
- ➖ Deduct Balance
- 📢 Force Join system
- 🗃️ MongoDB database

## 🔐 Environment Variables

The bot requires:

- `BOT_TOKEN`
- `MONGO_URI`
- `DATABASE_NAME`
- `ADMIN_ID`
- `BOT_USERNAME`

## 🛠️ Tech Stack

- 🐍 Python
- 🤖 python-telegram-bot
- 🍃 MongoDB
- 🚀 Heroku
- 🔐 python-dotenv
